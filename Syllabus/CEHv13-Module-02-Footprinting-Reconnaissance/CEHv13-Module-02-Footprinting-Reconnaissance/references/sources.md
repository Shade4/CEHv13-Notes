# Sources and Further Reading

This repository is an original study guide and does not reproduce proprietary course slides verbatim.

## Primary course reference

- EC-Council — Certified Ethical Hacker (CEH v13), Module 02: Footprinting and Reconnaissance.
- Official CEH program page: https://www.eccouncil.org/train-certify/certified-ethical-hacker-ceh-v13-north-america/

The official module description identifies topics including advanced search-engine footprinting, internet research services, social networking, WHOIS, DNS, traceroute, email footprinting, social engineering, and AI-powered OSINT.
