# Security Policy

## Scope

This repository is educational material for ethical hacking and reconnaissance.

## Responsible use

Do not use the techniques or examples here to access systems without authorization.

## Reporting a problem

If you find a security issue in this repository itself, document:

- Affected file
- Description
- Reproduction steps
- Potential impact
- Suggested remediation

Do not include real credentials, tokens, personal data, or other secrets in an issue.
