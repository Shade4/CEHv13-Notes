## How to use

### 1. Read in order

Start with:

`docs/module-01-introduction-to-ethical-hacking.md`

Then use:

- `docs/glossary.md` for terminology
- `docs/video-coverage.md` to jump to a topic by approximate video timestamp

### 2. Build your own revision cycle

For each topic:

1. Read the concept.
2. Explain it without looking at the notes.
3. Give yourself a real-world example.
4. Identify the defensive control.
5. Compare it with similar concepts.
6. Write a one- or two-line exam definition.
7. Review the related terms in the glossary.

### 3. Practical-learning rule

Only perform security testing against systems for which you have explicit authorization.

A safe progression is:

```text
Concept
   ↓
Threat model
   ↓
Controlled lab
   ↓
Observation
   ↓
Defensive mitigation
   ↓
Documentation
```

## Main learning outcome

The central idea of this module is:

> Ethical hacking uses attacker-style thinking and techniques for a defensive purpose, but the work is constrained by authorization, scope, law, safety, and professional responsibility.

Knowing a tool is less important than understanding:

- what it is trying to discover,
- why that information matters,
- what weakness it relates to,
- what evidence proves the weakness,
- what risk it creates,
- and how the organization can fix or monitor it.
